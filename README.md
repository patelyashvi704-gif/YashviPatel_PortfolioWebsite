👩‍💻 About the Project

The Personal Portfolio Website is a simple and responsive website designed to introduce me, present my technical skills, and showcase my academic and personal projects.

The website provides a central place where visitors can learn about my background, explore my skills, and understand my interests in technology and software development.

This project also demonstrates the practical use of Git and GitHub for version control, repository management, and website deployment.

🚀 Getting Started

Follow these steps to get a local copy of the project running.

📋 Prerequisites

Before starting, make sure you have:

- 💻 A computer or laptop.
- 🌐 A modern web browser.
- 📝 Visual Studio Code or another code editor.
- 🐙 A GitHub account if you want to upload or deploy the project.

📥 Installation

Step 1: Clone the repository

Open a terminal and run:

git clone YOUR_GITHUB_REPOSITORY_URL

Replace "YOUR_GITHUB_REPOSITORY_URL" with the actual URL of your GitHub repository.

Step 2: Open the project folder

cd YOUR_PROJECT_FOLDER

Replace "YOUR_PROJECT_FOLDER" with the actual folder name.

Step 3: Open the project in VS Code

code .

Alternatively, open VS Code and select File → Open Folder.

💻 How to Run the Project

1. 📂 Open the project folder in Visual Studio Code.
2. 🔎 Locate "index.html".
3. 🌐 Open the file in your web browser.
4. 🧭 Navigate through the available portfolio pages.
5. 🛠️ Edit "style.css" or "script.js" to customize the website.

You can also use the Live Server extension in VS Code for local development.

🌍 Deployment

This project can be hosted for free using GitHub Pages.

Deployment Steps

1. 📤 Push or upload all project files to your GitHub repository.
2. ⚙️ Open the repository on GitHub.
3. Select Settings.
4. Open Pages from the sidebar.
5. Under the build and deployment settings, select the appropriate branch, usually "main".
6. Select the root folder ("/") if your "index.html" is in the repository's root.
7. Click Save.
8. ⏳ Wait for GitHub Pages to publish the website.
9. 🌐 Open the published URL shown in the Pages settings.
